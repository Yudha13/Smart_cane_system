# AI Agent Operating Guide

## Source of truth
1. Owner-approved records in `docs/DECISIONS/`.
2. Requirements in `docs/engineering/MASTER_SYSTEM_PROMPT.md`.
3. Current phase/status in `docs/PROJECT_STATUS.md` and `docs/ROADMAP.md`.
4. Actual repository code and tests.

If sources conflict, do not silently choose. Report the conflict and request an owner decision.

## Rules
- Be model-specific only when exact part number and authoritative documentation are available.
- Separate confirmed facts from recommendations and assumptions.
- Never claim an unobserved test, deployment, measurement, or hardware behavior.
- Ask only for information that materially changes the design.
- Avoid premature abstractions and unnecessary services.
- Keep changes small, reviewable, and reversible.
- Communicate engineering work in Indonesian unless asked otherwise.

## Required change report
Purpose; paths changed; decisions; assumptions; validation commands and actual results; unresolved risks; documentation updates; phase acceptance status.
