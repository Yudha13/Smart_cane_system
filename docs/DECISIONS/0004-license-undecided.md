# ADR 0004: License Deferred

- Status: Open / Deferred
- Date: 2026-11-17
- Decision owner: Project owner

## Context
The owner has not selected a license.

## Decision
Do not add a `LICENSE` file or license badge yet. Do not imply that the repository is open source or that reuse/redistribution is permitted.

## Options for later review
- Apache-2.0 for software.
- CERN-OHL-S-2.0 for hardware design files if intentionally released as open hardware.
- A separate explicit license for documentation if required.

## Revisit when
The owner decides whether the project is intended to be public/open, proprietary, or mixed-license.
