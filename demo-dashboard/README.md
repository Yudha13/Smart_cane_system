# Smart Cane System — Dashboard Demo

Static, responsive dashboard preview for Netlify. This is a UI prototype only.

## Deploy to Netlify
1. Open Netlify and choose **Add new site → Import an existing project**.
2. Connect GitHub and select `Yudha13/Smart_cane_system`.
3. Set **Base directory** to `demo-dashboard`.
4. Leave **Build command** empty.
5. Set **Publish directory** to `.` (relative to the base directory).
6. Deploy.

Alternatively, drag and drop the `demo-dashboard` folder into Netlify Drop.

## Included
- Field overview, weather station, soil metrics, node status, alerts and telemetry table.
- Responsive layout for desktop and mobile.
- Interactive sensor metric selector and CSV export.
- Simulated live clock.

## Important
All displayed readings, node identities, locations, alerts, weather values and infrastructure statuses are fictional demo data. No sensor, Raspberry Pi, LoRaWAN gateway, server, authentication or production API is connected. Do not use the displayed values for operational decisions.
